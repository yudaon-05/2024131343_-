본 시스템은 대학 축제 티켓 예매 시 발생하는 트래픽 폭주(Congestion), 매크로를 이용한 취소표 선점(Front-running), 외부인 부정 예매 문제를 해결하고 공정하고 투명한 티켓 유통 체계를 수립하기 위해 설계된 학적 연동형 예매 시뮬레이터 및 실시간 보안 관제 시스템입니다.

고려대학교 포털(KUPID) 학적 데이터베이스를 모사하여 학번, 비밀번호뿐만 아니라 이름과 소속 학과를 수동 기입하여 무결성(Integrity)을 교차 확인합니다.

재학생, 휴학생, 교직원 신분만 예매가 승인되며, 졸업생이나 외부 대학 소속생 등 권한이 없는 접근 시도는 인증 단계에서 실시간으로 감지되어 원천 차단(Lockout)됩니다.

백엔드 API와 0.5초 간격으로 통신하는 고속 취소표 감지 리스너를 구현했습니다.

취소표 감지 및 이에 따른 초고속 자동 예매 인터럽트(0.15초 내 승인)는 사용자가 메인 화면에서 잔여석 발생 알림 메시지 수신 여부를 직접 동의로 설정(Opt-in)한 경우에만 작동하도록 설계하여, 불필요한 시스템 자원 낭비를 줄이고 사용자 선택권을 보장합니다.

잔여석(취소석) 발생 시 대기자 전원에게 동시에 알림을 보낼 경우 발생하는 2차 병목 현상(Thundering Herd Problem)을 차단하기 위해, 알림 수신 동의자 풀 중 무작위로 당첨 대상을 정밀 선정하여 분산 배포를 수행합니다.

다수의 잔여석이 발생하더라도 배포 메시지는 "취소석 1매 발생"이라는 타겟팅 메시지로 개개인에게 전달되어, 매크로 집중에 따른 사재기 현상을 예방하고 모든 대기자가 공정하게 기회를 얻도록 유도합니다.

카드 결제, 핸드폰 결제, 카카오페이, 무통장 입금 등 결제 방식 4종류별 완료/대기 건수를 실시간으로 독립 분리 계산하여 보여줍니다.

대량의 트래픽을 혼선 없이 관제할 수 있도록 로그를 단체 예매 / 개인-재학생 / 개인-휴학생 / 개인-기타(교직원, 졸업생, 차단)의 4개 터미널로 분할 라우팅하여 실시간 모니터링을 실현했습니다.

어드민에서 단체/개인 잔여 티켓 수량 옆의 증감 퀵 버튼(+100, +10, -10, -100)을 누르는 즉시 차트와 잔여량이 동기화되어 실시간 재고 제어가 가능합니다.

매크로 부정행위자나 비정상 접근 시도 학번을 어드민에서 실시간으로 블랙리스트로 등록할 수 있으며, 블랙리스트에 등록된 사용자는 로그인 시도 시 즉각 접근이 거부됩니다.
